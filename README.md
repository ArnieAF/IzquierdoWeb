# Inmobiliaria Izquierdo - Sitio Web Oficial

![Inmobiliaria Izquierdo Banner](src/assets/icons/Frame%204.svg)

## 🏢 Descripción del Proyecto

El sitio web oficial de **Inmobiliaria Izquierdo** ha sido desarrollado para presentar de manera profesional y atractiva los proyectos inmobiliarios de la empresa en Lima Metropolitana. Este sitio está diseñado bajo los más altos estándares de desarrollo web moderno, priorizando una experiencia de usuario (UX) óptima, un diseño visual impactante (UI) y una estructura completamente responsive.

El objetivo principal es mostrar proyectos destacados como **Perlamar** y **Los Cipreses**, resaltar los valores que diferencian a Izquierdo en el mercado y facilitar el contacto con clientes potenciales.

## ✨ Características Principales

* **Diseño Moderno y Atractivo:** Interfaz gráfica elegante que transmite profesionalismo y confianza, con el uso de tipografías modernas (Montserrat).
* **Carrusel Interactivo de Proyectos:** Presentación dinámica de los proyectos inmobiliarios en fase de lanzamiento.
* **100% Responsive:** Adaptabilidad total a cualquier dispositivo (smartphones, tablets, laptops y pantallas grandes).
* **Optimización SEO:** Estructura semántica de etiquetas HTML5 y metaetiquetas optimizadas para un mejor posicionamiento en motores de búsqueda.
* **Navegación Intuitiva:** Menú de navegación claro con acceso directo a "Proyectos en venta", "Conócenos" y "Contacto"..

## 🛠️ Tecnologías Utilizadas

Este proyecto ha sido construido utilizando tecnologías fundamentales del desarrollo web, garantizando velocidad y flexibilidad:

* **HTML5:** Estructura semántica y accesible.
* **CSS3:** Estilos personalizados, animaciones, Flexbox/Grid y diseño responsive (Media Queries).
* **JavaScript:** Lógica de interacción para carruseles, menús y dinamismo de la interfaz.

## 🚀 Instalación y Uso Local

Para desplegar este proyecto en tu entorno local, sigue estos sencillos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/IzquierdoWeb.git
   ```
2. **Navegar al directorio del proyecto:**
   ```bash
   cd IzquierdoWeb
   ```
3. **Ejecutar el proyecto:**
   Dado que es un proyecto basado en HTML/CSS/JS estático, simplemente puedes abrir el archivo `index.html` en tu navegador web preferido:
   * **Opción A:** Haz doble clic en el archivo `index.html`.
   * **Opción B:** Usa una extensión como *Live Server* en VS Code para una mejor experiencia de desarrollo con recarga en vivo.
